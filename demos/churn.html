Churn Model API: score a customer

This is the logistic regression the API serves, running in your browser. Change a customer's details and the churn risk, the reasons behind it, and the API response update instantly.

Trained on the public IBM Telco Customer Churn dataset (7,043 customers). Checked against the Python model on 40 holdout customers: the probabilities match to 15 decimal places and the top reasons match the API's /predict output exactly.
