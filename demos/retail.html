Retail Data Pipeline: KPI dashboard

Every number on this page comes from the pipeline's output: 59,089 messy raw rows, cleaned and modelled by dbt into a tested star schema in DuckDB. Filter by period and channel, and every chart below the filters updates together.

The store is fictional and the data is synthetic (fixed seed), generated with known data problems injected on purpose so the pipeline can be scored on whether it catches them. See the scorecard at the bottom.
